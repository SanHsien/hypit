元件把作者面對的創作想法與具體實現連線起來。對於榜單，這個想法可以是“說到每個候選時介紹它，再讓圖示移動到對應排名位置”。輸入表達這些關係，程式碼完成繪製和運動。

[新增作者包](./author-packages.md) 提供完整可構建的起點。[Ranking](https://github.com/hypit-ai/hypit/blob/main/packages/ranking/README.md) 則展示更豐富的語義事件、持久視覺狀態和 Studio Companion。

## 實現中的職責

這些職責可以按元件規模組織到合適的檔案中：

| 部分 | 職責 |
| --- | --- |
| Manifest 與 Types | 命名包提供的值、Producer、輸入和輸出 |
| Surface | 讀取作者元素，解析明確輸入 |
| Fragment | 描述輸入到輸出之間的操作與依賴 |
| Producer | 完成宣告的計算 |
| 值與樣式輔助函式 | 驗證輸入、應用已說明的預設值、解析接受的 Recipe 屬性 |
| 排程與繪製 | 投影事件，並在每一幀繪製場景 |
| Activation | 公開所選包提供的貢獻 |
| Studio Companion | 描述時間線實體與可編輯屬性 |

精確物件形狀由 [Author SDK](https://github.com/hypit-ai/hypit/blob/main/packages/author-kit/README.md) 和隨包示例維護。小元件可以把相關職責放在一起；大元件則可以分離可複用的排程、樣式和繪製邏輯。

## 圍繞關係設計

對於說話影片，接受 Selection 和 Moment 來表達隨詞語發生的行為。表演產生後，投影提供準確區間與時刻。作者決定節奏的動畫可以使用秒或幀；`12f` 這樣的時長在兩種情況下都能表達一次轉場的長度。

素材呈現、空間佈局與時間各有自己的輸入。歸一化影片提供可取樣素材，Timeline 可以提供準備好的表演及其素材位置。Frame 定位場景，內部 HTML/CSS 或元素樹協調影片、文字、遮罩和圖形。共享行為的內容組織在一起，獨立貢獻可以繼續作為具有自己繪製順序的 Track。

字幕元件可以沿用已有字幕文件、樣式選擇與語義時間。細粒度字幕族能表達的樣式可以直接使用；新的樣式族則可以消費相同字幕關係，繪製不同的視覺呈現。

## 讓另一個作者用得好

從創作決定命名引數：出現事件、內容、位置、外觀。說明預設值和覆蓋後改變什麼。Style 解碼器接收 `{ path, properties }` 形狀的 SVS Recipe 與明確字型資源，Source 透過作者 id 引用 Style。

具體影片的文案和媒體作為輸入。元件繪製自己的圖形結構，也可以攜帶可複用字型或圖示等資源。示例 Source 展示關鍵狀態，包括換內容或改變事件時間後的行為。

包的 README 與 vocabulary 幫助作者選擇和使用元件。Studio Companion 可以為含義明確的 Source 值新增編輯手柄。新的視覺行為在元件包內實現；圖需要外部執行時，由 Provider 完成。
