---
title: 與 Agent 一起製作影片
description: 把參考影片或創作 Brief 交給 Agent，得到可繼續編輯的影片作品。
---

把參考影片、創作 Brief，或兩者一起交給 Agent。你可以提供人物照片、產品、Logo 或已有素材，並說明新影片要達到什麼目標。Agent 理解這些材料，形成創意方案，再讓畫面、表演、圖形、聲音和剪輯共同服務於作品。

## 安裝 Skill

[在你的 Agent 中使用 Hypit](./agents.md)介紹工作環境與 Agent 入口合作方。

```bash
npx skills add hypit-ai/hypit -g
```

Skill 提供製作知識，可執行的 `hypit` 包提供命令、元件、Runtime 和 Studio。Agent 可以找到已有的可執行安裝，或準備選定的發行版本。Skill、可執行程式和影片專案各有自己的位置，也透過各自的安裝渠道更新。

## 發展作品

理解參考片會在整片與細節之間往返：開頭為什麼抓人，表演怎樣推進論述，畫面、字幕、圖形和聲音各自發揮什麼作用。帶詞時間的轉寫與幀序列幫助定位細節：什麼出現了，如何運動，為什麼在此刻重要。Agent 把整體理解與精確觀察記入專案的參考筆記。

製作目標片會在意圖與可見結果之間往返。換人物或產品，可能同時影響劇本、表演、場景和收尾，也會改變參考圖片。Agent 圍繞新的目標想清楚這些關係，在生成素材前，把視覺形象、參考關係、發音與表演方向寫進圖片 Prompt、Script 和影片 Prompt。等待生成時，可以同時製作元件與字幕。真實素材到位後，集中檢查視覺層次、位置、出入場和時機是否承載了預期效果。

目標、私有事實、服務賬戶和花費由你決定。Agent 檢查相關已有能力，在缺少某項能力時解釋選擇。例如，理解說話參考片可能需要準備本地 WhisperX 或選擇託管轉寫；圖片、影片生成可以透過支援的服務使用你自己的 Key，或使用 HypiHub 賬戶。

付費工作前，根據可用價格資訊確認賬戶、製作範圍與預算。Agent 在委託內承擔日常創作與技術決定，說明理解與製作進展；範圍或費用變化時再交給你決定。

## 保持專案可編輯

作品儲存在普通專案檔案裡：

- 參考筆記解釋原片的整體結構和可定位細節。
- Brief 與 Treatment 分別記錄使用者目標和 Agent 的創意方案。
- `.svml` 表達 Script、媒體、元件和合成；`.svs` 儲存可複用的 Recipe。
- `.svrun` 選擇 Author Source、已有 Output 和本次執行的目標。
- Build Result 留存實際產物與本次執行的事實。

專案元件是影片製作的一部分。它們與專案一起儲存，可以表達新的視覺角色、Caption 樣式族或圖形行為。共享佈局或動作的內容可以組織為同一場景，獨立圖形與字幕繼續分開。說話影片用 Script 事件驅動這些關係，純視覺動畫則可以使用作者宣告的時鐘。需要跨專案共享時，可以透過所有者自己的 scope 釋出普通的版本化包。

修改作品時，Run 可以複用已有 Result 中仍適用的 Output，也包括失敗 Build 在失敗前已經產出的可用素材。新的 Build 執行修改後的 Run。Studio 顯示這份作品，並把支援的編輯寫回 Source；Agent 對照目標審看實際成片。
